# Café Prisma - Landing

Landing page conceptual para una cafetería de especialidad moderna, diseñada con un enfoque minimalista, alta velocidad de carga y animaciones fluidas de alto rendimiento.

## Tecnologías Utilizadas

- **HTML5 & CSS3:**
- **Tailwind CSS:**
- **GSAP (GreenSock Animation Platform):** Animacion de los textos y el smooth scroll
- **JavaScript (ES6+):**

## Características Principales

- **Enfoque Mobile-First / Completamente Responsive:** Adaptado para cualquier dispositivo
- **Animaciones:** Hovers en botones y transiciones de entrada fluidas gestionadas por GSAP.
- **Arquitectura Limpia:** Estructura de código orientada a un SEO óptimo.

## Instalación y Uso Local

Si quieres clonar este repositorio y ejecutarlo en tu máquina local, sigue estos pasos:

1. Clona el repositorio:

```bash
    git clone https://github.com/angelandrescode/CoffeWeb.git
```

2. Entra en el directorio del proyecto:

```bash
    cd cafe-web
```

3. Instalas dependencias

```bash
    npm i
```

4. Iniciar el servidor de desarrollo local

```bash
    npm run dev
```
